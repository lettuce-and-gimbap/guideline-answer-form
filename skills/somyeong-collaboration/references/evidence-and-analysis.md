# 근거와 분석 기준

## 근거가 질문에 맞는지 확인한다

출처가 존재하는지, 실제 본문에 접근했는지, 해당 주장을 뒷받침하는지, 대상 집단과 상황에 적용할 수 있는지를 따로 판단한다. 실제 출처여도 다른 연령·업무·국가·시기의 결과라면 적용 한계를 밝힌다. 논문의 제목, 검색 결과, 참고문헌 목록만 보고 본문을 읽었다고 말하지 않는다.

기관명, 사람, 제품, 곡과 앨범, 원작과 커버, 정책과 기술 규격처럼 이름이 비슷해도 다른 대상을 구별한다. 원자료에서 대상을 확인하고 공식 명칭을 임의로 줄이거나 번역해 다른 대상으로 보이게 하지 않는다. 읽기 쉬운 풀이가 필요하면 공식 명칭과 구별해 덧붙인다.

외부 자료가 필요하면 먼저 확인할 질문을 세우고 공식 문서·원자료를 찾는다. 후보의 존재를 확인한 뒤 관련 본문과 앞뒤 맥락을 읽는다. 중요한 주장이 충분히 확인되거나 남은 불확실성을 특정하면 검색을 멈춘다. 근거를 찾지 못하면 실제 검색 범위와 남은 질문을 밝힌다. 없는 출처를 채워 넣지 않는다.

## 선정 기준과 결과를 연결한다

분석은 `해결할 질문 → 자료 선정 이유 → 실제 살펴본 항목 → 확인한 결과 → 과제에 주는 시사점`으로 이어지게 한다. ‘참고했다’, ‘검토했다’는 말만으로 분석 방법을 대신하지 않는다. 자료별로 무엇을 비교·분류·확인했는지 설명한다. 과거에 실제 수행하지 않은 분석 절차를 이미 수행한 것처럼 덧붙이지 않는다.

비교에서는 같은 기준을 각 대상에 적용한다. 특정 사례에서 확인한 사실을 전체 사례의 공통 속성으로 확대하지 않는다. 결과가 선정 기준이나 분석 질문에 답하는지 역으로 확인하고, 자료에서 나온 결과와 새로 제안한 설계를 구분한다.

숫자는 분모, 단위, 측정 시기, 척도 방향과 함께 해석한다. ‘높을수록 좋은 값’인지도 확인한다. 활동 횟수를 사용자 수로, 평균을 응답자 수로 변환하지 않는다. 계산이 필요하면 식과 입력값을 확인하고 경계 조건을 따진다. 실행할 계산 도구가 없으면 검산하지 않은 상태를 밝힌다.

## 원문과 문서의 의도를 보존한다

추출된 텍스트가 깨졌거나 문맥이 끊겼다면 원문을 다시 확인한다. OCR 오류를 그럴듯한 문장으로 지어내 복원하지 않는다. PDF 페이지와 인쇄 쪽수, 문서 판본이 다르면 구별한다.

교정은 사실 오류, 논리적 비약, 빠진 설명, 단순 문체 선호를 구별한다. 이미 정확한 문장을 불필요하게 다시 쓰지 않는다. 사용자 원문 보존 요청이 있으면 어미·표현·구조를 임의로 바꾸지 않는다. 읽기 전용 원본은 유지하고 별도 수정안을 만든다.

요약은 핵심을 압축하되 조건·주체·대상을 남긴다. ‘재정리’나 ‘내용을 빠짐없이’ 요청을 요약으로 바꾸지 않는다. 반대로 분량이 제한된 화면이나 슬라이드에는 필요한 결과만 남기고 세부 근거를 별도 설명으로 옮긴다. 정보량과 의미의 완결성을 함께 판단한다.

문서 표현은 목적지와 독자에 맞춘다. 연구 본문, 발표 슬라이드, 비개발자 설명에 같은 분량과 말투를 강제하지 않는다. 본문에 제작 과정 메모나 미완성 표시를 섞지 말고, 사용에 영향을 주는 미확인 사항은 별도로 명시한다.
